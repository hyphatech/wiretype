# Reference

Every module's interface, generated by odoc from its `.mli`, where each
function says what it does, what it refuses and when it raises.

## The packages

The two are released together, at one version. A `dune` file names a
library as it is installed (`ppx_wiretype`); OCaml code names it as a
module (`Wiretype`).

| Package | Libraries | What it is |
|---|---|---|
| `wiretype` | `wiretype` | descriptions: reading, writing, bounds, kinds, schemas; links Ptime, Mtime and Uuidm alone |
| `ppx_wiretype` | `ppx_wiretype` | `[@@deriving wiretype]`, which writes a type's description |

## wiretype

- [`Wiretype`](https://hyphatech.github.io/wiretype/reference/wiretype/Wiretype/index.html) -- the
  combinators, the kinds, `decode` and `encode`. Its modules:
  [`Object`](https://hyphatech.github.io/wiretype/reference/wiretype/Wiretype/Object/index.html),
  [`Tuple`](https://hyphatech.github.io/wiretype/reference/wiretype/Wiretype/Tuple/index.html) and
  [`Value`](https://hyphatech.github.io/wiretype/reference/wiretype/Wiretype/Value/index.html).
- [`Wiretype.Problem`](https://hyphatech.github.io/wiretype/reference/wiretype/Wiretype/Problem/index.html)
  -- what a reader is told: a path, a code and a sentence.
- [`Wiretype.Unwritable`](https://hyphatech.github.io/wiretype/reference/wiretype/Wiretype/Unwritable/index.html)
  -- what a writer is told.
- [`Wiretype.Schema`](https://hyphatech.github.io/wiretype/reference/wiretype/Wiretype/Schema/index.html)
  -- one walk into a schema, printed as
  [JSON Schema](https://hyphatech.github.io/wiretype/reference/wiretype/Wiretype/Schema/Json_schema/index.html),
  [Zod](https://hyphatech.github.io/wiretype/reference/wiretype/Wiretype/Schema/Zod/index.html) and
  [Melange](https://hyphatech.github.io/wiretype/reference/wiretype/Wiretype/Schema/Melange/index.html).
- [`Wiretype.Shape`](https://hyphatech.github.io/wiretype/reference/wiretype/Wiretype/Shape/index.html)
  -- the GADT a description is.
- [`Wiretype.Text`](https://hyphatech.github.io/wiretype/reference/wiretype/Wiretype/Text/index.html)
  -- JSON's spellings of a number and a string.

## ppx_wiretype

- [`Ppx_wiretype`](https://hyphatech.github.io/wiretype/reference/ppx_wiretype/Ppx_wiretype/index.html)
  -- `[@@deriving wiretype]`: every type it reads, and every attribute.
